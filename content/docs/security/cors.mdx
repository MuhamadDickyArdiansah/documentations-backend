## Overview

CORS adalah kebijakan browser untuk membaca response lintas origin. CORS tidak mencegah server lain mengirim request dan bukan pengganti authentication atau CSRF protection.

## Concept

Fokus penerapan **CORS** adalah allowlist origin. Hindari wildcard dengan credentials. Batasi method dan header. Contoh berikut memperlihatkan konteks kategori Security; sesuaikan dengan kontrak dan batas resource aplikasi.

## Prerequisites

- Node.js LTS yang masih didukung, npm, dan terminal.
- Materi [Getting Started](/docs/getting-started) dan dasar async/await.
- Folder latihan terpisah agar perubahan tidak memengaruhi data production.

## Implementation

1. Allowlist origin.
2. Hindari wildcard dengan credentials.
3. Batasi method dan header.

### Contoh terfokus

Cuplikan ini berfokus pada konsep di atas. Untuk fragmen middleware, daftarkan pada aplikasi Express setelah dependensi yang dibutuhkan; contoh aplikasi lengkap tersedia pada Project References.

```js title="cors.mjs"
// Middleware allowlist minimal. Untuk konfigurasi lengkap gunakan paket cors.
export function allowedOrigin(req, res, next) {
  const origin = req.headers.origin;
  if (origin && origin !== "https://app.example.com") return res.status(403).end();
  if (origin) { res.setHeader("Access-Control-Allow-Origin", origin); res.vary("Origin"); }
  next();
}
// Ini bukan authentication dan tidak menangani seluruh preflight.
```

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk CORS, verifikasi langkah “Allowlist origin” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.

## Security & Best Practices

<Callout type="warn" title="Batas implementasi">Contoh adalah sarana belajar dan bukan audit keamanan. Untuk production, gunakan TLS, shared persistent storage, rate limit terdistribusi, serta pengelolaan secret yang sesuai infrastruktur.</Callout>

- Hindari wildcard dengan credentials.
- Batasi hak akses dan data yang dikirim ke client.
- Batasi method dan header.
