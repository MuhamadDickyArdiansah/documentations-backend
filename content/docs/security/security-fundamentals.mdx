## Overview

Keamanan dimulai dengan threat model: aset, aktor, entry point, dan dampak. Kontrol berlapis membantu ketika satu asumsi atau komponen gagal.

## Concept

Fokus penerapan **Security Fundamentals** adalah inventarisasi data sensitif. Tentukan trust boundary. Uji abuse case selain happy path. Contoh berikut memperlihatkan konteks kategori Security; sesuaikan dengan kontrak dan batas resource aplikasi.

## Prerequisites

- Node.js LTS yang masih didukung, npm, dan terminal.
- Materi [Getting Started](/docs/getting-started) dan dasar async/await.
- Folder latihan terpisah agar perubahan tidak memengaruhi data production.

## Installation

Contoh kategori ini memakai Node.js atau tools yang disebut pada contoh. Untuk berkas .mjs, jalankan node diikuti nama file.

## Project Structure

Simpan latihan Security Fundamentals pada module fitur terkait. Pisahkan transport HTTP, aturan bisnis, dan akses data agar dapat diuji secara mandiri.

```text title="struktur referensi"
src/
  features/
    notes/
      notes.routes.mjs
      notes.service.mjs
      notes.repository.mjs
  app.mjs
  server.mjs
```

## Implementation

1. Inventarisasi data sensitif.
2. Tentukan trust boundary.
3. Uji abuse case selain happy path.

### Contoh terfokus

Periksa dependensi dan konteks pada komentar kode. Adapter seperti repository, provider, atau prisma diberikan oleh composition root; fragmen bukan server terpisah. Untuk contoh utuh, lihat [Complete Backend Starter](/docs/projects/complete-backend-starter).

```text title="security-fundamentals.text"
Aset: credential, data pribadi, note pengguna
Entry point: JSON body, URL params, query, upload, webhook
Kontrol: schema, auth, ownership, limit, TLS, audit
Verifikasi: unit test policy + integration test lintas user
```

### Konteks kategori

```js title="safe-compare.mjs"
import { timingSafeEqual } from "node:crypto";
export function equalDigest(a, b) {
  if (!Buffer.isBuffer(a) || !Buffer.isBuffer(b)) return false;
  return a.length === b.length && timingSafeEqual(a, b);
}
```

## API Examples

Topik ini merupakan konsep internal, sehingga tidak mendefinisikan endpoint tersendiri. Gunakan [Basic Express API](/docs/projects/basic-express-api) untuk mempelajari cara menerapkannya pada request HTTP.

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk Security Fundamentals, verifikasi langkah “Inventarisasi data sensitif” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.

## Security & Best Practices

<Callout type="warn" title="Batas implementasi">Contoh adalah sarana belajar dan bukan audit keamanan. Untuk production, gunakan TLS, shared persistent storage, rate limit terdistribusi, serta pengelolaan secret yang sesuai infrastruktur.</Callout>

- Tentukan trust boundary.
- Batasi hak akses dan data yang dikirim ke client.
- Uji abuse case selain happy path.
