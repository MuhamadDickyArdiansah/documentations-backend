## Tentang kategori ini

Keamanan dimulai dengan threat model: aset, aktor, entry point, dan dampak. Kontrol berlapis membantu ketika satu asumsi atau komponen gagal.

## Praktik

Jalankan contoh lokal dengan `npm run examples` dari root repository. Untuk pemeriksaan perilaku authentication dan CRUD, gunakan `npm run test:examples`.

## Referensi

- **Referensi dari [OWASP — REST Security Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/REST_Security_Cheat_Sheet.html)** — Kontrol keamanan pada endpoint dan data API.
