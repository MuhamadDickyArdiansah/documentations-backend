## Overview

Token adalah credential dan harus diperlakukan seperti password selama valid. Payload JWT dapat dibaca; jangan simpan secret atau data sensitif di dalamnya.

## Concept

Fokus penerapan **Token Security** adalah gunakan TLS. Redact token dari log. Rotasi key dan tetapkan umur pendek. Contoh berikut memperlihatkan konteks kategori Security; sesuaikan dengan kontrak dan batas resource aplikasi.

## Prerequisites

- Node.js LTS yang masih didukung, npm, dan terminal.
- Materi [Getting Started](/docs/getting-started) dan dasar async/await.
- Folder latihan terpisah agar perubahan tidak memengaruhi data production.

## Implementation

1. Gunakan TLS.
2. Redact token dari log.
3. Rotasi key dan tetapkan umur pendek.

### Contoh terfokus

Cuplikan ini berfokus pada konsep di atas. Untuk fragmen middleware, daftarkan pada aplikasi Express setelah dependensi yang dibutuhkan; contoh aplikasi lengkap tersedia pada Project References.

```js title="token-security.mjs"
import { randomBytes, createHash } from "node:crypto";
const token = randomBytes(32).toString("base64url");
const hash = createHash("sha256").update(token).digest("hex");
// Simpan hash + expiry pada server, kirim token sekali melalui saluran aman.
```

### Konteks kategori

```js title="safe-compare.mjs"
import { timingSafeEqual } from "node:crypto";
export function equalDigest(a, b) {
  if (!Buffer.isBuffer(a) || !Buffer.isBuffer(b)) return false;
  return a.length === b.length && timingSafeEqual(a, b);
}
```

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk Token Security, verifikasi langkah “Gunakan TLS” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.

## Security & Best Practices

<Callout type="warn" title="Batas implementasi">Contoh adalah sarana belajar dan bukan audit keamanan. Untuk production, gunakan TLS, shared persistent storage, rate limit terdistribusi, serta pengelolaan secret yang sesuai infrastruktur.</Callout>

- Redact token dari log.
- Batasi hak akses dan data yang dikirim ke client.
- Rotasi key dan tetapkan umur pendek.
