## Overview

Security headers mengurangi beberapa kelas serangan browser. Content Security Policy harus disesuaikan dengan asset dan script aplikasi agar tidak merusak fitur atau terlalu permisif.

## Concept

Fokus penerapan **Helmet & Security Headers** adalah pasang Helmet. Tinjau CSP. Aktifkan HSTS setelah HTTPS konsisten. Contoh berikut memperlihatkan konteks kategori Security; sesuaikan dengan kontrak dan batas resource aplikasi.

## Prerequisites

- Node.js LTS yang masih didukung, npm, dan terminal.
- Materi [Getting Started](/docs/getting-started) dan dasar async/await.
- Folder latihan terpisah agar perubahan tidak memengaruhi data production.

## Installation

Contoh kategori ini memakai Node.js atau tools yang disebut pada contoh. Untuk berkas .mjs, jalankan node diikuti nama file.

## Project Structure

Simpan latihan Helmet & Security Headers pada module fitur terkait. Pisahkan transport HTTP, aturan bisnis, dan akses data agar dapat diuji secara mandiri.

## Implementation

1. Pasang Helmet.
2. Tinjau CSP.
3. Aktifkan HSTS setelah HTTPS konsisten.

### Contoh terfokus

Cuplikan ini berfokus pada konsep di atas. Untuk fragmen middleware, daftarkan pada aplikasi Express setelah dependensi yang dibutuhkan; contoh aplikasi lengkap tersedia pada Project References.

```js title="helmet-and-security-headers.mjs"
import helmet from "helmet";
import express from "express";
const app = express();
app.use(helmet());
app.disable("x-powered-by");
```

### Konteks kategori

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk Helmet & Security Headers, verifikasi langkah “Pasang Helmet” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.

## Security & Best Practices

<Callout type="warn" title="Batas implementasi">Contoh adalah sarana belajar dan bukan audit keamanan. Untuk production, gunakan TLS, shared persistent storage, rate limit terdistribusi, serta pengelolaan secret yang sesuai infrastruktur.</Callout>

- Tinjau CSP.
- Batasi hak akses dan data yang dikirim ke client.
- Aktifkan HSTS setelah HTTPS konsisten.
