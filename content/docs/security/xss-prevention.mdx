## Overview

XSS terjadi ketika data tak terpercaya dieksekusi sebagai kode pada browser. API tetap perlu menjaga tipe konten dan frontend perlu melakukan output encoding sesuai konteks.

## Concept

Fokus penerapan **XSS Prevention** adalah return application/json. Hindari innerHTML. Sanitasi rich text dengan library yang dirawat. Contoh berikut memperlihatkan konteks kategori Security; sesuaikan dengan kontrak dan batas resource aplikasi.

## Prerequisites

- Node.js LTS yang masih didukung, npm, dan terminal.
- Materi [Getting Started](/docs/getting-started) dan dasar async/await.
- Folder latihan terpisah agar perubahan tidak memengaruhi data production.

## Installation

Contoh kategori ini memakai Node.js atau tools yang disebut pada contoh. Untuk berkas .mjs, jalankan node diikuti nama file.

## Implementation

1. Return application/json.
2. Hindari innerHTML.
3. Sanitasi rich text dengan library yang dirawat.

### Contoh terfokus

Periksa dependensi dan konteks pada komentar kode. Adapter seperti repository, provider, atau prisma diberikan oleh composition root; fragmen bukan server terpisah. Untuk contoh utuh, lihat [Complete Backend Starter](/docs/projects/complete-backend-starter).

```js title="xss-prevention.mjs"
// Pada frontend: textContent memperlakukan data sebagai teks, bukan HTML.
export function renderMessage(element, userMessage) {
  element.textContent = userMessage;
}
// API: res.type("application/json").send(payload). Jangan render rich text mentah.
```

### Konteks kategori

```js title="safe-compare.mjs"
import { timingSafeEqual } from "node:crypto";
export function equalDigest(a, b) {
  if (!Buffer.isBuffer(a) || !Buffer.isBuffer(b)) return false;
  return a.length === b.length && timingSafeEqual(a, b);
}
```

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk XSS Prevention, verifikasi langkah “Return application/json” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.

## Security & Best Practices

<Callout type="warn" title="Batas implementasi">Contoh adalah sarana belajar dan bukan audit keamanan. Untuk production, gunakan TLS, shared persistent storage, rate limit terdistribusi, serta pengelolaan secret yang sesuai infrastruktur.</Callout>
