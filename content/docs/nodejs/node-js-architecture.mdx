## Overview

JavaScript berjalan pada thread utama. Sebagian operasi filesystem dan crypto menggunakan thread pool libuv, sedangkan network I/O umumnya memakai fasilitas sistem operasi.

## Concept

Fokus penerapan **Node.js Architecture** adalah pisahkan tugas CPU dan I/O. Ukur event loop lag. Gunakan worker_threads untuk komputasi berat. Contoh berikut memperlihatkan konteks kategori Node.js; sesuaikan dengan kontrak dan batas resource aplikasi.

## Prerequisites

- Node.js LTS yang masih didukung, npm, dan terminal.
- Materi [Getting Started](/docs/getting-started) dan dasar async/await.
- Folder latihan terpisah agar perubahan tidak memengaruhi data production.

### Konteks kategori

```js title="server.mjs"
import { createServer } from "node:http";
const server = createServer((req, res) => {
  res.writeHead(200, { "Content-Type": "application/json" });
  res.end(JSON.stringify({ data: { status: "ok" } }));
});
server.listen(4000, "127.0.0.1");
```

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk Node.js Architecture, verifikasi langkah “Pisahkan tugas CPU dan I/O” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.
