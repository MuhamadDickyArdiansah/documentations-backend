## Overview

Node.js menggabungkan V8, event loop, dan API sistem. Model ini sesuai untuk server dengan banyak I/O, tetapi tidak membuat operasi CPU otomatis paralel.

## Concept

Fokus penerapan **Introduction to Node.js** adalah gunakan ESM. Pelajari API node:http. Jangan gunakan API browser seperti document. Contoh berikut memperlihatkan konteks kategori Node.js; sesuaikan dengan kontrak dan batas resource aplikasi.

## Prerequisites

- Node.js LTS yang masih didukung, npm, dan terminal.
- Materi [Getting Started](/docs/getting-started) dan dasar async/await.
- Folder latihan terpisah agar perubahan tidak memengaruhi data production.

## Installation

Contoh kategori ini memakai Node.js atau tools yang disebut pada contoh. Untuk berkas .mjs, jalankan node diikuti nama file.

Simpan latihan Introduction to Node.js pada module fitur terkait. Pisahkan transport HTTP, aturan bisnis, dan akses data agar dapat diuji secara mandiri.

## Implementation

1. Gunakan ESM.
2. Pelajari API node:http.
3. Jangan gunakan API browser seperti document.

### Contoh terfokus

Periksa dependensi dan konteks pada komentar kode. Adapter seperti repository, provider, atau prisma diberikan oleh composition root; fragmen bukan server terpisah. Untuk contoh utuh, lihat [Complete Backend Starter](/docs/projects/complete-backend-starter).

```js title="introduction-to-node-js.mjs"
import { versions, platform } from "node:process";
console.log({ node: versions.node, v8: versions.v8, platform });
```

### Konteks kategori

```js title="server.mjs"
import { createServer } from "node:http";
const server = createServer((req, res) => {
  res.writeHead(200, { "Content-Type": "application/json" });
  res.end(JSON.stringify({ data: { status: "ok" } }));
});
server.listen(4000, "127.0.0.1");
```

## Code Explanation

Node.js menggabungkan V8, event loop, dan API sistem. Model ini sesuai untuk server dengan banyak I/O, tetapi tidak membuat operasi CPU otomatis paralel. Dalam implementasi nyata, pelajari api node:http dan jangan gunakan api browser seperti document sebelum meneruskan hasil ke bagian aplikasi berikutnya.

## API Examples

Topik ini merupakan konsep internal, sehingga tidak mendefinisikan endpoint tersendiri. Gunakan [Basic Express API](/docs/projects/basic-express-api) untuk mempelajari cara menerapkannya pada request HTTP.

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk Introduction to Node.js, verifikasi langkah “Gunakan ESM” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.
