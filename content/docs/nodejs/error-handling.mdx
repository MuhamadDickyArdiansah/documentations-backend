## Overview

Error event pada stream harus ditangani. uncaughtException menunjukkan state proses tidak lagi dapat dipercaya; hentikan secara terkontrol dan biarkan supervisor melakukan restart.

## Concept

Fokus penerapan **Error Handling** adalah tangani error pada boundary. Hindari menangkap lalu mengabaikan error. Lakukan graceful shutdown. Contoh berikut memperlihatkan konteks kategori Node.js; sesuaikan dengan kontrak dan batas resource aplikasi.

## Prerequisites

- Node.js LTS yang masih didukung, npm, dan terminal.
- Materi [Getting Started](/docs/getting-started) dan dasar async/await.
- Folder latihan terpisah agar perubahan tidak memengaruhi data production.

## Implementation

1. Tangani error pada boundary.
2. Hindari menangkap lalu mengabaikan error.
3. Lakukan graceful shutdown.

### Contoh terfokus

Cuplikan ini berfokus pada konsep di atas. Untuk fragmen middleware, daftarkan pada aplikasi Express setelah dependensi yang dibutuhkan; contoh aplikasi lengkap tersedia pada Project References.

```js title="error-handling.mjs"
import { pipeline } from "node:stream/promises";
import { createReadStream, createWriteStream } from "node:fs";
// Kedua path berasal dari konfigurasi server, bukan input bebas.
await pipeline(createReadStream("input.txt"), createWriteStream("output.txt"));
// pipeline meneruskan error dan membersihkan stream.
```

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk Error Handling, verifikasi langkah “Tangani error pada boundary” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.
