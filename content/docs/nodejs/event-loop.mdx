## Overview

Event loop menjadwalkan callback ketika operasi siap. Microtask diproses setelah eksekusi JavaScript saat ini; antrean microtask yang tak berakhir dapat menunda I/O.

## Concept

Fokus penerapan **Event Loop** adalah hindari loop sinkron panjang. Gunakan setImmediate untuk memberi kesempatan I/O. Jangan bergantung pada urutan timer presisi. Contoh berikut memperlihatkan konteks kategori Node.js; sesuaikan dengan kontrak dan batas resource aplikasi.

## Implementation

1. Hindari loop sinkron panjang.
2. Gunakan setImmediate untuk memberi kesempatan I/O.
3. Jangan bergantung pada urutan timer presisi.

### Contoh terfokus

Cuplikan ini berfokus pada konsep di atas. Untuk fragmen middleware, daftarkan pada aplikasi Express setelah dependensi yang dibutuhkan; contoh aplikasi lengkap tersedia pada Project References.

```js title="event-loop.mjs"
console.log("sync");
queueMicrotask(() => console.log("microtask"));
setImmediate(() => console.log("check phase"));
// sync -> microtask -> check phase
```

### Konteks kategori

```js title="server.mjs"
import { createServer } from "node:http";
const server = createServer((req, res) => {
  res.writeHead(200, { "Content-Type": "application/json" });
  res.end(JSON.stringify({ data: { status: "ok" } }));
});
server.listen(4000, "127.0.0.1");
```

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk Event Loop, verifikasi langkah “Hindari loop sinkron panjang” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.
