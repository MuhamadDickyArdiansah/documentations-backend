## Overview

Environment variable dikirim sebagai string. Validasi konfigurasi sekali saat startup sehingga aplikasi gagal cepat jika konfigurasi wajib tidak tersedia.

## Concept

Fokus penerapan **Environment Variables** adalah pisahkan .env dari Git. Parse port sebagai angka. Jangan gunakan prefix public untuk secret. Contoh berikut memperlihatkan konteks kategori Node.js; sesuaikan dengan kontrak dan batas resource aplikasi.

## Prerequisites

- Node.js LTS yang masih didukung, npm, dan terminal.
- Materi [Getting Started](/docs/getting-started) dan dasar async/await.
- Folder latihan terpisah agar perubahan tidak memengaruhi data production.

## Installation

Contoh kategori ini memakai Node.js atau tools yang disebut pada contoh. Untuk berkas .mjs, jalankan node diikuti nama file.

## Implementation

1. Pisahkan .env dari Git.
2. Parse port sebagai angka.
3. Jangan gunakan prefix public untuk secret.

### Contoh terfokus

Cuplikan ini berfokus pada konsep di atas. Untuk fragmen middleware, daftarkan pada aplikasi Express setelah dependensi yang dibutuhkan; contoh aplikasi lengkap tersedia pada Project References.

```js title="environment-variables.mjs"
const port = Number(process.env.PORT ?? 4000);
if (!Number.isInteger(port) || port < 1 || port > 65535) {
  throw new Error("PORT harus integer 1–65535");
}
console.log({ port }); // Jangan log seluruh process.env.
```

### Konteks kategori

```js title="server.mjs"
import { createServer } from "node:http";
const server = createServer((req, res) => {
  res.writeHead(200, { "Content-Type": "application/json" });
  res.end(JSON.stringify({ data: { status: "ok" } }));
});
server.listen(4000, "127.0.0.1");
```

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk Environment Variables, verifikasi langkah “Pisahkan .env dari Git” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.
