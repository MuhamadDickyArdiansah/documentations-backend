## Overview

API node:fs/promises mendukung operasi file tanpa memblokir thread utama. Input path dari user dapat menyebabkan path traversal jika tidak dibatasi pada direktori yang diizinkan.

## Concept

Fokus penerapan **File System** adalah gunakan path.resolve. Batasi direktori tujuan. Tangani ENOENT tanpa membocorkan absolute path. Contoh berikut memperlihatkan konteks kategori Node.js; sesuaikan dengan kontrak dan batas resource aplikasi.

## Implementation

1. Gunakan path.resolve.
2. Batasi direktori tujuan.
3. Tangani ENOENT tanpa membocorkan absolute path.

### Contoh terfokus

Cuplikan ini berfokus pada konsep di atas. Untuk fragmen middleware, daftarkan pada aplikasi Express setelah dependensi yang dibutuhkan; contoh aplikasi lengkap tersedia pada Project References.

```js title="file-system.mjs"
import { readFile } from "node:fs/promises";
try {
  const content = await readFile(new URL("./config.json", import.meta.url), "utf8");
  console.log(JSON.parse(content));
} catch (error) {
  if (error.code === "ENOENT") console.error("Config tidak tersedia");
  else throw error;
}
```
