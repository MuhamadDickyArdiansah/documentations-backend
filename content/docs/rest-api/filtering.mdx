## Overview

Filter menerjemahkan parameter yang diizinkan menjadi kondisi query. Filter database harus digabung dengan scope kepemilikan, bukan menggantikannya.

## Concept

Fokus penerapan **Filtering** adalah allowlist field dan operator. Validasi rentang tanggal. Tambahkan ownerId pada kondisi query. Contoh berikut memperlihatkan konteks kategori REST API; sesuaikan dengan kontrak dan batas resource aplikasi.

## Implementation

1. Allowlist field dan operator.
2. Validasi rentang tanggal.
3. Tambahkan ownerId pada kondisi query.

### Contoh terfokus

Cuplikan ini berfokus pada konsep di atas. Untuk fragmen middleware, daftarkan pada aplikasi Express setelah dependensi yang dibutuhkan; contoh aplikasi lengkap tersedia pada Project References.

```js title="filtering.mjs"
const notes = [{ ownerId: "u1", archived: false }, { ownerId: "u2", archived: false }];
const actor = { id: "u1" };
const filtered = notes.filter(n => n.ownerId === actor.id && !n.archived);
console.assert(filtered.length === 1);
```

## API Examples

Contoh API lokal menggunakan resource notes. Endpoint mutasi membutuhkan bearer access token hasil login.

| Method | Endpoint | Authentication | Hasil |
| --- | --- | --- | --- |
| GET | /health | Tidak | 200, status proses |
| POST | /api/auth/login | Tidak | 200, pasangan token |
| GET | /api/notes | Bearer token | 200, daftar milik actor |
| POST | /api/notes | Bearer token | 201, note baru |

```json title="POST /api/notes — request"
{"title":"Belajar backend"}
```

```json title="201 — response shape"
{"data":{"id":"<note-id>","ownerId":"<user-id>","title":"Belajar backend"}}
```

Kirim header Content-Type: application/json. Token dan ID pada response merupakan placeholder; gunakan nilai dari server lokal. Lihat [Complete Backend Starter](/docs/projects/complete-backend-starter) untuk alur lengkap.

## Error Handling

Gunakan 401 untuk credential tidak valid, 404 untuk record yang tidak tersedia dalam scope actor, 409 untuk konflik, dan 422 untuk body yang tidak memenuhi schema. Response error berbentuk object error dengan code dan message. Untuk Filtering, verifikasi langkah “Allowlist field dan operator” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.
