## Overview

Offset pagination sederhana tetapi biaya query meningkat pada offset besar. Cursor pagination menggunakan urutan stabil dan cocok untuk daftar yang terus berubah.

## Concept

Fokus penerapan **Pagination** adalah batasi limit. Tambahkan tie-breaker ID. Return nextCursor tanpa membocorkan field sensitif. Contoh berikut memperlihatkan konteks kategori REST API; sesuaikan dengan kontrak dan batas resource aplikasi.

## Implementation

1. Batasi limit.
2. Tambahkan tie-breaker ID.
3. Return nextCursor tanpa membocorkan field sensitif.

### Contoh terfokus

Cuplikan ini berfokus pada konsep di atas. Untuk fragmen middleware, daftarkan pada aplikasi Express setelah dependensi yang dibutuhkan; contoh aplikasi lengkap tersedia pada Project References.

```js title="pagination.mjs"
export function paginate(rows, page = 1, limit = 20) {
  if (!Number.isInteger(page) || page < 1 || !Number.isInteger(limit) || limit < 1 || limit > 100) {
    throw new RangeError("Pagination tidak valid");
  }
  return rows.slice((page - 1) * limit, page * limit);
}
```

## API Examples

Contoh API lokal menggunakan resource notes. Endpoint mutasi membutuhkan bearer access token hasil login.

| Method | Endpoint | Authentication | Hasil |
| --- | --- | --- | --- |
| GET | /health | Tidak | 200, status proses |
| POST | /api/auth/login | Tidak | 200, pasangan token |
| GET | /api/notes | Bearer token | 200, daftar milik actor |
| POST | /api/notes | Bearer token | 201, note baru |

```json title="POST /api/notes — request"
{"title":"Belajar backend"}
```

```json title="201 — response shape"
{"data":{"id":"<note-id>","ownerId":"<user-id>","title":"Belajar backend"}}
```

Kirim header Content-Type: application/json. Token dan ID pada response merupakan placeholder; gunakan nilai dari server lokal. Lihat [Complete Backend Starter](/docs/projects/complete-backend-starter) untuk alur lengkap.

## Error Handling

Gunakan 401 untuk credential tidak valid, 404 untuk record yang tidak tersedia dalam scope actor, 409 untuk konflik, dan 422 untuk body yang tidak memenuhi schema. Response error berbentuk object error dengan code dan message. Untuk Pagination, verifikasi langkah “Batasi limit” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.
