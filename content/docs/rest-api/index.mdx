## Tentang kategori ini

REST memodelkan resource yang diidentifikasi URL. Gunakan HTTP method sesuai semantiknya dan hindari menyimpan konteks percakapan tersembunyi pada server.

## Praktik

Jalankan contoh lokal dengan `npm run examples` dari root repository. Untuk pemeriksaan perilaku authentication dan CRUD, gunakan `npm run test:examples`.

## Referensi

Sumber konsep dan bacaan lanjutan untuk materi ini:

- **Referensi dari [IETF — RFC 9110: HTTP Semantics](https://www.rfc-editor.org/rfc/rfc9110)** — Semantik method, status code, header, dan representasi.
- **Referensi dari [Microsoft — REST API Guidelines](https://github.com/microsoft/api-guidelines)** — Desain resource, daftar hasil, filtering, dan kontrak API.

Penjelasan dan contoh kode pada handbook ditulis sebagai materi pembelajaran mandiri; bukan salinan resmi dari sumber tersebut. Cocokkan versi API pada referensi dengan versi dependensi contoh.
