## Overview

Sort menentukan urutan hasil dan perlu tie-breaker agar pagination stabil. Jangan memakai nama kolom mentah dari client dalam raw SQL.

## Concept

Fokus penerapan **Sorting** adalah allowlist sort key. Batasi arah asc atau desc. Tambahkan ID sebagai urutan kedua. Contoh berikut memperlihatkan konteks kategori REST API; sesuaikan dengan kontrak dan batas resource aplikasi.

## Implementation

1. Allowlist sort key.
2. Batasi arah asc atau desc.
3. Tambahkan ID sebagai urutan kedua.

### Contoh terfokus

Cuplikan ini berfokus pada konsep di atas. Untuk fragmen middleware, daftarkan pada aplikasi Express setelah dependensi yang dibutuhkan; contoh aplikasi lengkap tersedia pada Project References.

```js title="sorting.mjs"
const rows = [{ id: "b", title: "B" }, { id: "a", title: "A" }];
const sorted = [...rows].sort((a, b) => a.title.localeCompare(b.title) || a.id.localeCompare(b.id));
console.log(sorted.map(row => row.id)); // a, b
```

## API Examples

Contoh API lokal menggunakan resource notes. Endpoint mutasi membutuhkan bearer access token hasil login.

| Method | Endpoint | Authentication | Hasil |
| --- | --- | --- | --- |
| GET | /health | Tidak | 200, status proses |
| POST | /api/auth/login | Tidak | 200, pasangan token |
| GET | /api/notes | Bearer token | 200, daftar milik actor |
| POST | /api/notes | Bearer token | 201, note baru |

```json title="POST /api/notes — request"
{"title":"Belajar backend"}
```

```json title="201 — response shape"
{"data":{"id":"<note-id>","ownerId":"<user-id>","title":"Belajar backend"}}
```

Kirim header Content-Type: application/json. Token dan ID pada response merupakan placeholder; gunakan nilai dari server lokal. Lihat [Complete Backend Starter](/docs/projects/complete-backend-starter) untuk alur lengkap.

## Error Handling

Gunakan 401 untuk credential tidak valid, 404 untuk record yang tidak tersedia dalam scope actor, 409 untuk konflik, dan 422 untuk body yang tidak memenuhi schema. Response error berbentuk object error dengan code dan message. Untuk Sorting, verifikasi langkah “Allowlist sort key” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.
