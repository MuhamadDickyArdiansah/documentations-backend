## Overview

Dependensi eksternal memiliki latency dan kegagalan terpisah. Timeout, retry terbatas, dan circuit breaker mencegah satu provider melumpuhkan seluruh aplikasi.

## Concept

Fokus penerapan **External API Integration** adalah gunakan AbortSignal.timeout. Retry hanya operasi yang aman. Validasi response provider. Contoh berikut memperlihatkan konteks kategori Advanced Backend; sesuaikan dengan kontrak dan batas resource aplikasi.

- Node.js LTS yang masih didukung, npm, dan terminal.

## Implementation

1. Gunakan AbortSignal.timeout.
2. Retry hanya operasi yang aman.
3. Validasi response provider.

### Contoh terfokus

Cuplikan ini berfokus pada konsep di atas. Untuk fragmen middleware, daftarkan pada aplikasi Express setelah dependensi yang dibutuhkan; contoh aplikasi lengkap tersedia pada Project References.

```js title="external-api-integration.mjs"
export async function providerJSON(url) {
  const response = await fetch(url, { signal: AbortSignal.timeout(5000) });
  if (!response.ok) throw new Error(`Provider failed: ${response.status}`);
  return response.json();
}
// url dari konfigurasi allowlist server; validasi schema response.
```

### Konteks kategori

```js title="fetch.mjs"
export async function readJSON(url) {
  const response = await fetch(url, { signal: AbortSignal.timeout(5000) });
  if (!response.ok) throw new Error(`Provider returned ${response.status}`);
  return response.json();
}
// Gunakan URL dari konfigurasi server, bukan URL bebas dari user.
```

## Code Explanation

Dependensi eksternal memiliki latency dan kegagalan terpisah. Timeout, retry terbatas, dan circuit breaker mencegah satu provider melumpuhkan seluruh aplikasi. Dalam implementasi nyata, retry hanya operasi yang aman dan validasi response provider sebelum meneruskan hasil ke bagian aplikasi berikutnya.

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk External API Integration, verifikasi langkah “Gunakan AbortSignal.timeout” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.

## Security & Best Practices

<Callout type="info" title="Batas implementasi">Contoh ringkas memperlihatkan konsep dan perlu disesuaikan dengan validasi, authorization, serta observability aplikasi.</Callout>
