## Overview

Upload besar sebaiknya mengalir sebagai stream atau langsung ke object storage dengan signed URL. Buffer seluruh file dapat menghabiskan memory server.

## Concept

Fokus penerapan **File Upload** adalah batasi ukuran. Generate storage key di server. Verifikasi ownership sebelum download. Contoh berikut memperlihatkan konteks kategori Advanced Backend; sesuaikan dengan kontrak dan batas resource aplikasi.

## Prerequisites

- Node.js LTS yang masih didukung, npm, dan terminal.
- Materi [Getting Started](/docs/getting-started) dan dasar async/await.
- Folder latihan terpisah agar perubahan tidak memengaruhi data production.

## Implementation

1. Batasi ukuran.
2. Generate storage key di server.
3. Verifikasi ownership sebelum download.

### Contoh terfokus

Periksa dependensi dan konteks pada komentar kode. Adapter seperti repository, provider, atau prisma diberikan oleh composition root; fragmen bukan server terpisah. Untuk contoh utuh, lihat [Complete Backend Starter](/docs/projects/complete-backend-starter).

```js title="file-upload.mjs"
import { pipeline } from "node:stream/promises";
import { createWriteStream } from "node:fs";
import { randomUUID } from "node:crypto";
export async function saveVerifiedStream(stream, directory) {
  const key = randomUUID();
  await pipeline(stream, createWriteStream(`${directory}/${key}`, { flags: "wx", mode: 0o600 }));
  return key;
}
// directory dari server; parser harus lebih dulu membatasi size dan memverifikasi tipe.
```

### Konteks kategori

```js title="fetch.mjs"
export async function readJSON(url) {
  const response = await fetch(url, { signal: AbortSignal.timeout(5000) });
  if (!response.ok) throw new Error(`Provider returned ${response.status}`);
  return response.json();
}
// Gunakan URL dari konfigurasi server, bukan URL bebas dari user.
```

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk File Upload, verifikasi langkah “Batasi ukuran” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.
