## Overview

### Contoh terfokus

Periksa dependensi dan konteks pada komentar kode. Adapter seperti repository, provider, atau prisma diberikan oleh composition root; fragmen bukan server terpisah. Untuk contoh utuh, lihat [Complete Backend Starter](/docs/projects/complete-backend-starter).

```js title="email-service.mjs"
export function emailService(provider) {
  return {
    async sendVerification({ recipient, verificationUrl, eventId }) {
      const url = new URL(verificationUrl);
      if (url.protocol !== "https:") throw new Error("Verification URL harus HTTPS");
      return provider.send({ to: recipient, template: "verify-email", variables: { url: url.href }, idempotencyKey: eventId });
    },
  };
}
// Provider adapter wajib melakukan escape data template.
```

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk Email Service, verifikasi langkah “Gunakan provider adapter” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.
