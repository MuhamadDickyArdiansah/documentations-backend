## Overview

Scheduler multi-instance dapat menjalankan tugas yang sama beberapa kali. Gunakan leader lock atau scheduler terpusat dan catat eksekusi agar tugas tidak hilang tanpa jejak.

## Concept

Fokus penerapan **Scheduled Tasks** adalah tetapkan timezone eksplisit. Gunakan lock dengan expiry. Tangani job yang melewati jadwal berikutnya. Contoh berikut memperlihatkan konteks kategori Advanced Backend; sesuaikan dengan kontrak dan batas resource aplikasi.

## Prerequisites

- Node.js LTS yang masih didukung, npm, dan terminal.
- Materi [Getting Started](/docs/getting-started) dan dasar async/await.
- Folder latihan terpisah agar perubahan tidak memengaruhi data production.

## Installation

Contoh kategori ini memakai Node.js atau tools yang disebut pada contoh. Untuk berkas .mjs, jalankan node diikuti nama file.

## Implementation

1. Tetapkan timezone eksplisit.
2. Gunakan lock dengan expiry.
3. Tangani job yang melewati jadwal berikutnya.

### Contoh terfokus

Cuplikan ini berfokus pada konsep di atas. Untuk fragmen middleware, daftarkan pada aplikasi Express setelah dependensi yang dibutuhkan; contoh aplikasi lengkap tersedia pada Project References.

```js title="scheduled-tasks.mjs"
const interval = setInterval(() => {
  console.log({ at: new Date().toISOString(), task: "local-heartbeat" });
}, 60_000);
interval.unref();
// Untuk tugas terjadwal persisten: scheduler terpusat + lock dan riwayat eksekusi.
```

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk Scheduled Tasks, verifikasi langkah “Tetapkan timezone eksplisit” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.

## Security & Best Practices
