## Overview

Webhook adalah request dari layanan lain yang harus diverifikasi sebelum diproses. Signature biasanya dihitung atas raw body, sehingga parsing JSON tidak boleh mengubah byte yang diverifikasi.

## Concept

Fokus penerapan **Webhooks** adalah verifikasi HMAC secara constant-time. Cek timestamp untuk replay. Simpan event ID sebelum efek samping. Contoh berikut memperlihatkan konteks kategori Advanced Backend; sesuaikan dengan kontrak dan batas resource aplikasi.

## Implementation

1. Verifikasi HMAC secara constant-time.
2. Cek timestamp untuk replay.
3. Simpan event ID sebelum efek samping.

### Contoh terfokus

Cuplikan ini berfokus pada konsep di atas. Untuk fragmen middleware, daftarkan pada aplikasi Express setelah dependensi yang dibutuhkan; contoh aplikasi lengkap tersedia pada Project References.

```js title="webhooks.mjs"
import { createHmac, timingSafeEqual } from "node:crypto";
export function verify(rawBody, signatureHex, secret) {
  const expected = createHmac("sha256", secret).update(rawBody).digest();
  const actual = Buffer.from(signatureHex, "hex");
  return actual.length === expected.length && timingSafeEqual(actual, expected);
}
// rawBody harus byte asli. Tambahkan timestamp dan event ID untuk menolak replay.
```

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk Webhooks, verifikasi langkah “Verifikasi HMAC secara constant-time” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.
