## Tentang kategori ini

Environment production harus divalidasi sebelum menerima traffic. Pisahkan build-time public configuration dari runtime secret dan hindari fallback credential pada production.

## Praktik

Jalankan contoh lokal dengan `npm run examples` dari root repository. Untuk pemeriksaan perilaku authentication dan CRUD, gunakan `npm run test:examples`.
