## Overview

Node.js menjalankan JavaScript di luar browser. Gunakan rilis LTS yang masih didukung dan version manager agar pergantian versi tidak mengganggu project lain.

## Concept

Fokus penerapan **Node.js Installation** adalah periksa node --version. Periksa npm --version. Catat versi runtime dalam .nvmrc. Contoh berikut memperlihatkan konteks kategori Getting Started; sesuaikan dengan kontrak dan batas resource aplikasi.

## Prerequisites

- Node.js LTS yang masih didukung, npm, dan terminal.
- Pemahaman dasar fungsi JavaScript dan object JSON.
- Folder latihan terpisah agar perubahan tidak memengaruhi data production.

## Installation

Contoh kategori ini memakai Node.js atau tools yang disebut pada contoh. Untuk berkas .mjs, jalankan node diikuti nama file.

## Project Structure

Simpan latihan Node.js Installation pada module fitur terkait. Pisahkan transport HTTP, aturan bisnis, dan akses data agar dapat diuji secara mandiri.

```text title="struktur referensi"
src/
  features/
    notes/
      notes.routes.mjs
      notes.service.mjs
      notes.repository.mjs
  app.mjs
  server.mjs
```

## Implementation

1. Periksa node --version.
2. Periksa npm --version.
3. Catat versi runtime dalam .nvmrc.

### Contoh terfokus

Periksa dependensi dan konteks pada komentar kode. Adapter seperti repository, provider, atau prisma diberikan oleh composition root; fragmen bukan server terpisah. Untuk contoh utuh, lihat [Complete Backend Starter](/docs/projects/complete-backend-starter).

```bash title="node-js-installation.bash"
node --version
npm --version
# Pastikan versinya sesuai LTS yang dipilih untuk project.
# Jika terminal tidak menemukan node, buka terminal baru setelah instalasi.
```

### Konteks kategori

```bash title="terminal"
node --version
npm --version
npm init -y
npm install express
```

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk Node.js Installation, verifikasi langkah “Periksa node --version” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.

## Security & Best Practices

<Callout type="info" title="Batas implementasi">Contoh ringkas memperlihatkan konsep dan perlu disesuaikan dengan validasi, authorization, serta observability aplikasi.</Callout>

- Periksa npm --version.
- Batasi hak akses dan data yang dikirim ke client.
- Catat versi runtime dalam .nvmrc.

## Testing

Uji Node.js Installation dengan input valid, input kosong, dan kegagalan dependensi. Pastikan perilaku “periksa node --version” sesuai kontrak.
