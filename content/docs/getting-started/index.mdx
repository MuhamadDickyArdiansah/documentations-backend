## Tentang kategori ini

Backend menerima request, menjalankan aturan bisnis, dan menyimpan data. Pisahkan kontrak HTTP dari logika bisnis agar keduanya dapat diuji secara mandiri.

## Praktik

Jalankan contoh lokal dengan `npm run examples` dari root repository. Untuk pemeriksaan perilaku authentication dan CRUD, gunakan `npm run test:examples`.

## Referensi

Sumber konsep dan bacaan lanjutan untuk materi ini:

- **Referensi dari [Node.js — Introduction to Node.js](https://nodejs.org/en/learn/getting-started/introduction-to-nodejs)** — Model runtime dan dasar penggunaan Node.js.
- **Referensi dari [MDN Web Docs — JavaScript Guide](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide)** — Sintaks, tipe data, fungsi, object, modules, dan asynchronous programming.

Penjelasan dan contoh kode pada handbook ditulis sebagai materi pembelajaran mandiri; bukan salinan resmi dari sumber tersebut. Cocokkan versi API pada referensi dengan versi dependensi contoh.
