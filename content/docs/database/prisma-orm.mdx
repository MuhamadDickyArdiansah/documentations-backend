## Overview

Prisma menyediakan schema dan client bertipe. Type safety tidak menggantikan constraint database, authorization, maupun transaksi untuk operasi lintas record.

## Concept

Fokus penerapan **Prisma ORM** adalah definisikan schema. Generate client. Gunakan select untuk membatasi field. Contoh berikut memperlihatkan konteks kategori Database; sesuaikan dengan kontrak dan batas resource aplikasi.

## Prerequisites

- Node.js LTS yang masih didukung, npm, dan terminal.
- Materi [Getting Started](/docs/getting-started) dan dasar async/await.
- Folder latihan terpisah agar perubahan tidak memengaruhi data production.

## Installation

Contoh kategori ini memakai PostgreSQL. Jalankan SQL pada database development melalui psql atau SQL editor.

## Project Structure

Simpan latihan Prisma ORM pada module fitur terkait. Pisahkan transport HTTP, aturan bisnis, dan akses data agar dapat diuji secara mandiri.

## Implementation

1. Definisikan schema.
2. Generate client.
3. Gunakan select untuk membatasi field.

### Contoh terfokus

Periksa dependensi dan konteks pada komentar kode. Adapter seperti repository, provider, atau prisma diberikan oleh composition root; fragmen bukan server terpisah. Untuk contoh utuh, lihat [Complete Backend Starter](/docs/projects/complete-backend-starter).

```js title="prisma-orm.mjs"
// Contoh ini secara eksplisit untuk Prisma 6.19, bukan API versi lain.
// Project latihan: npm install @prisma/client@6.19.0
// Dev tooling: npm install --save-dev prisma@6.19.0
import { PrismaClient } from "@prisma/client";
const prisma = new PrismaClient();
try {
  const notes = await prisma.note.findMany({ where: { ownerId: "<user-id>" }, select: { id: true, title: true }, take: 20 });
  console.log(notes);
} finally { await prisma.$disconnect(); }
// Memerlukan model Note, migration, DATABASE_URL, dan prisma generate.
```

### Konteks kategori

```sql title="schema.sql"
CREATE TABLE notes (
  id uuid PRIMARY KEY,
  owner_id uuid NOT NULL,
  title varchar(200) NOT NULL CHECK (length(title) > 0),
  created_at timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX notes_owner_created_idx ON notes(owner_id, created_at DESC, id);
```

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk Prisma ORM, verifikasi langkah “Definisikan schema” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.
