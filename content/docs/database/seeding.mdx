## Overview

Seed menciptakan data awal yang dapat diulang. Seed production harus dibedakan dari fixture development agar akun contoh tidak muncul pada layanan nyata.

## Concept

Fokus penerapan **Seeding** adalah gunakan upsert. Hindari credential default. Buat seed idempotent. Contoh berikut memperlihatkan konteks kategori Database; sesuaikan dengan kontrak dan batas resource aplikasi.

## Prerequisites

- Node.js LTS yang masih didukung, npm, dan terminal.
- Materi [Getting Started](/docs/getting-started) dan dasar async/await.
- Folder latihan terpisah agar perubahan tidak memengaruhi data production.

## Installation

Contoh kategori ini memakai PostgreSQL. Jalankan SQL pada database development melalui psql atau SQL editor.

## Implementation

1. Gunakan upsert.
2. Hindari credential default.
3. Buat seed idempotent.

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk Seeding, verifikasi langkah “Gunakan upsert” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.

## Security & Best Practices
