## Overview

Foreign key menjaga hubungan antar record. Tentukan perilaku delete secara sengaja karena cascade dapat menghapus data lebih luas dari yang diharapkan.

## Concept

Fokus penerapan **Database Relationships** adalah modelkan one-to-many. Buat join table untuk many-to-many. Tinjau cascade sebelum migration. Contoh berikut memperlihatkan konteks kategori Database; sesuaikan dengan kontrak dan batas resource aplikasi.

- Node.js LTS yang masih didukung, npm, dan terminal.

## Implementation

1. Modelkan one-to-many.
2. Buat join table untuk many-to-many.
3. Tinjau cascade sebelum migration.

### Contoh terfokus

Cuplikan ini berfokus pada konsep di atas. Untuk fragmen middleware, daftarkan pada aplikasi Express setelah dependensi yang dibutuhkan; contoh aplikasi lengkap tersedia pada Project References.

```sql title="database-relationships.sql"
CREATE TABLE user_notes (
  id uuid PRIMARY KEY,
  owner_id uuid NOT NULL REFERENCES users(id) ON DELETE RESTRICT,
  title varchar(200) NOT NULL
);
CREATE INDEX user_notes_owner_idx ON user_notes(owner_id);
```

### Konteks kategori

```sql title="schema.sql"
CREATE TABLE notes (
  id uuid PRIMARY KEY,
  owner_id uuid NOT NULL,
  title varchar(200) NOT NULL CHECK (length(title) > 0),
  created_at timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX notes_owner_created_idx ON notes(owner_id, created_at DESC, id);
```

## Code Explanation

Foreign key menjaga hubungan antar record. Tentukan perilaku delete secara sengaja karena cascade dapat menghapus data lebih luas dari yang diharapkan. Dalam implementasi nyata, buat join table untuk many-to-many dan tinjau cascade sebelum migration sebelum meneruskan hasil ke bagian aplikasi berikutnya.

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk Database Relationships, verifikasi langkah “Modelkan one-to-many” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.

## Security & Best Practices

<Callout type="info" title="Batas implementasi">Contoh ringkas memperlihatkan konsep dan perlu disesuaikan dengan validasi, authorization, serta observability aplikasi.</Callout>

- Buat join table untuk many-to-many.
- Batasi hak akses dan data yang dikirim ke client.
- Tinjau cascade sebelum migration.
