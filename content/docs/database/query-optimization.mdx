## Overview

Mulai optimasi dengan query plan dan metrik nyata. N+1 query, overfetching, dan pagination tanpa index sering lebih berdampak daripada perubahan kecil di JavaScript.

## Concept

Fokus penerapan **Query Optimization** adalah gunakan EXPLAIN ANALYZE di lingkungan aman. Pilih kolom yang diperlukan. Batasi jumlah record. Contoh berikut memperlihatkan konteks kategori Database; sesuaikan dengan kontrak dan batas resource aplikasi.

## Implementation

1. Gunakan EXPLAIN ANALYZE di lingkungan aman.
2. Pilih kolom yang diperlukan.
3. Batasi jumlah record.

### Contoh terfokus

Cuplikan ini berfokus pada konsep di atas. Untuk fragmen middleware, daftarkan pada aplikasi Express setelah dependensi yang dibutuhkan; contoh aplikasi lengkap tersedia pada Project References.

```sql title="query-optimization.sql"
EXPLAIN (ANALYZE, BUFFERS)
SELECT id, title FROM user_notes
WHERE owner_id = '00000000-0000-4000-8000-000000000001'
ORDER BY title, id LIMIT 20;
-- ANALYZE benar-benar menjalankan query. Gunakan lingkungan yang aman.
```

### Konteks kategori

```sql title="schema.sql"
CREATE TABLE notes (
  id uuid PRIMARY KEY,
  owner_id uuid NOT NULL,
  title varchar(200) NOT NULL CHECK (length(title) > 0),
  created_at timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX notes_owner_created_idx ON notes(owner_id, created_at DESC, id);
```
