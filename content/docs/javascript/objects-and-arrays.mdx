## Overview

## Concept

Fokus penerapan **Objects & Arrays** adalah destructure field yang digunakan. Gunakan optional chaining untuk akses opsional. Pilih field response dengan allowlist. Contoh berikut memperlihatkan konteks kategori JavaScript & TypeScript; sesuaikan dengan kontrak dan batas resource aplikasi.

1. Destructure field yang digunakan.
2. Gunakan optional chaining untuk akses opsional.
3. Pilih field response dengan allowlist.

### Contoh terfokus

Cuplikan ini berfokus pada konsep di atas. Untuk fragmen middleware, daftarkan pada aplikasi Express setelah dependensi yang dibutuhkan; contoh aplikasi lengkap tersedia pada Project References.

```js title="objects-and-arrays.mjs"
const user = { id: "u1", email: "reader@example.com", passwordHash: "internal" };
const { id, email } = user;
const response = { id, email };
console.assert(!("passwordHash" in response));
```

### Konteks kategori

```js title="example.mjs"
const notes = [{ id: 1, title: "Belajar backend", done: false }];
const titles = notes.filter(note => !note.done).map(note => note.title);
console.log(titles);
```

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk Objects & Arrays, verifikasi langkah “Destructure field yang digunakan” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.
