## Overview

const melarang reassignment tetapi tidak membuat object immutable. Nilai null berarti kosong secara eksplisit, sedangkan undefined berarti nilai belum disediakan.

## Concept

Fokus penerapan **Variables & Data Types** adalah utamakan const. Gunakan let untuk nilai yang berubah. Validasi data dari request pada runtime. Contoh berikut memperlihatkan konteks kategori JavaScript & TypeScript; sesuaikan dengan kontrak dan batas resource aplikasi.

## Implementation

1. Utamakan const.
2. Gunakan let untuk nilai yang berubah.
3. Validasi data dari request pada runtime.

### Contoh terfokus

Cuplikan ini berfokus pada konsep di atas. Untuk fragmen middleware, daftarkan pada aplikasi Express setelah dependensi yang dibutuhkan; contoh aplikasi lengkap tersedia pada Project References.

```js title="variables-and-data-types.mjs"
const config = { port: 4000 };
config.port = 5000; // const tidak membuat object immutable
console.log(typeof config.port); // number
console.log(null === undefined); // false
```

### Konteks kategori

```js title="example.mjs"
const notes = [{ id: 1, title: "Belajar backend", done: false }];
const titles = notes.filter(note => !note.done).map(note => note.title);
console.log(titles);
```

## Code Explanation

const melarang reassignment tetapi tidak membuat object immutable. Nilai null berarti kosong secara eksplisit, sedangkan undefined berarti nilai belum disediakan. Dalam implementasi nyata, gunakan let untuk nilai yang berubah dan validasi data dari request pada runtime sebelum meneruskan hasil ke bagian aplikasi berikutnya.

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk Variables & Data Types, verifikasi langkah “Utamakan const” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.
