## Overview

Promise mewakili hasil operasi yang akan selesai. Promise.all gagal ketika satu operasi ditolak; Promise.allSettled memberi hasil semua operasi, termasuk yang gagal.

## Concept

Fokus penerapan **Promise** adalah return promise dari fungsi. Tangani rejection. Gunakan allSettled untuk tugas independen. Contoh berikut memperlihatkan konteks kategori JavaScript & TypeScript; sesuaikan dengan kontrak dan batas resource aplikasi.

## Implementation

1. Return promise dari fungsi.
2. Tangani rejection.
3. Gunakan allSettled untuk tugas independen.

### Contoh terfokus

Cuplikan ini berfokus pada konsep di atas. Untuk fragmen middleware, daftarkan pada aplikasi Express setelah dependensi yang dibutuhkan; contoh aplikasi lengkap tersedia pada Project References.

```js title="promise.mjs"
const results = await Promise.allSettled([
  Promise.resolve("ok"),
  Promise.reject(new Error("Provider unavailable")),
]);
console.log(results.map(result => result.status)); // fulfilled, rejected
```

### Konteks kategori

```js title="example.mjs"
const notes = [{ id: 1, title: "Belajar backend", done: false }];
const titles = notes.filter(note => !note.done).map(note => note.title);
console.log(titles);
```

## Code Explanation

Promise mewakili hasil operasi yang akan selesai. Promise.all gagal ketika satu operasi ditolak; Promise.allSettled memberi hasil semua operasi, termasuk yang gagal. Dalam implementasi nyata, tangani rejection dan gunakan allsettled untuk tugas independen sebelum meneruskan hasil ke bagian aplikasi berikutnya.

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk Promise, verifikasi langkah “Return promise dari fungsi” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.
