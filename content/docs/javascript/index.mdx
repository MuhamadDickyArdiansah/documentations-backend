## Tentang kategori ini

JavaScript memiliki dynamic typing dan lexical scope. Di backend, efek samping seperti operasi database sebaiknya berada pada batas aplikasi, sementara transformasi data dibuat sebagai fungsi murni.

## Praktik

Jalankan contoh lokal dengan `npm run examples` dari root repository. Untuk pemeriksaan perilaku authentication dan CRUD, gunakan `npm run test:examples`.
