## Overview

ES modules menggunakan import dan export. Dengan type module di package.json, gunakan ekstensi file pada import relatif agar contoh dapat dijalankan langsung oleh Node.js.

## Concept

Fokus penerapan **Modules** adalah export API modul secara eksplisit. Hindari circular dependency. Pisahkan module utilitas dari inisialisasi server. Contoh berikut memperlihatkan konteks kategori JavaScript & TypeScript; sesuaikan dengan kontrak dan batas resource aplikasi.

## Prerequisites

- Node.js LTS yang masih didukung, npm, dan terminal.
- Materi [Getting Started](/docs/getting-started) dan dasar async/await.
- Folder latihan terpisah agar perubahan tidak memengaruhi data production.

## Installation

Contoh kategori ini memakai Node.js atau tools yang disebut pada contoh. Untuk berkas .mjs, jalankan node diikuti nama file.

## Project Structure

Simpan latihan Modules pada module fitur terkait. Pisahkan transport HTTP, aturan bisnis, dan akses data agar dapat diuji secara mandiri.

```text title="struktur referensi"
src/
  features/
    notes/
      notes.routes.mjs
      notes.service.mjs
      notes.repository.mjs
  app.mjs
  server.mjs
```

## Implementation

1. Export API modul secara eksplisit.
2. Hindari circular dependency.
3. Pisahkan module utilitas dari inisialisasi server.

### Contoh terfokus

Cuplikan ini berfokus pada konsep di atas. Untuk fragmen middleware, daftarkan pada aplikasi Express setelah dependensi yang dibutuhkan; contoh aplikasi lengkap tersedia pada Project References.

```js title="modules.mjs"
// math.mjs
export const sum = (a, b) => a + b;
// Pada main.mjs yang terpisah:
// import { sum } from "./math.mjs";
// console.log(sum(2, 3)); // 5
```

### Konteks kategori

```js title="example.mjs"
const notes = [{ id: 1, title: "Belajar backend", done: false }];
const titles = notes.filter(note => !note.done).map(note => note.title);
console.log(titles);
```

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk Modules, verifikasi langkah “Export API modul secara eksplisit” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.

## Security & Best Practices

<Callout type="info" title="Batas implementasi">Contoh ringkas memperlihatkan konsep dan perlu disesuaikan dengan validasi, authorization, serta observability aplikasi.</Callout>

- Hindari circular dependency.
- Batasi hak akses dan data yang dikirim ke client.
- Pisahkan module utilitas dari inisialisasi server.

## Testing
