## Overview

TypeScript memeriksa tipe saat build dan menghapus tipe ketika kode dijalankan. TypeScript tidak memvalidasi JSON dari jaringan; parsing runtime tetap diperlukan.

## Concept

Fokus penerapan **TypeScript Fundamentals** adalah aktifkan strict. Gunakan unknown untuk input eksternal. Narrow tipe sebelum mengakses properti. Contoh berikut memperlihatkan konteks kategori JavaScript & TypeScript; sesuaikan dengan kontrak dan batas resource aplikasi.

## Implementation

1. Aktifkan strict.
2. Gunakan unknown untuk input eksternal.
3. Narrow tipe sebelum mengakses properti.

### Contoh terfokus

Cuplikan ini berfokus pada konsep di atas. Untuk fragmen middleware, daftarkan pada aplikasi Express setelah dependensi yang dibutuhkan; contoh aplikasi lengkap tersedia pada Project References.

```ts title="typescript-fundamentals.ts"
function readTitle(value: unknown): string {
  if (typeof value !== "string") throw new Error("Title harus string");
  return value.trim();
}
console.log(readTitle("Backend"));
```

### Konteks kategori

```js title="example.mjs"
const notes = [{ id: 1, title: "Belajar backend", done: false }];
const titles = notes.filter(note => !note.done).map(note => note.title);
console.log(titles);
```

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk TypeScript Fundamentals, verifikasi langkah “Aktifkan strict” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.
