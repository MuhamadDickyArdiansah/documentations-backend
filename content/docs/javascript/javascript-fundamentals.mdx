## Overview

JavaScript memiliki dynamic typing dan lexical scope. Di backend, efek samping seperti operasi database sebaiknya berada pada batas aplikasi, sementara transformasi data dibuat sebagai fungsi murni.

## Concept

Fokus penerapan **JavaScript Fundamentals** adalah gunakan strict equality. Pisahkan input dan output. Hindari mutasi data bersama. Contoh berikut memperlihatkan konteks kategori JavaScript & TypeScript; sesuaikan dengan kontrak dan batas resource aplikasi.

```js title="example.mjs"
const notes = [{ id: 1, title: "Belajar backend", done: false }];
const titles = notes.filter(note => !note.done).map(note => note.title);
console.log(titles);
```

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk JavaScript Fundamentals, verifikasi langkah “Gunakan strict equality” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.
