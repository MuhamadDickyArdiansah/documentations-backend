## Overview

Operasi I/O tidak harus menahan thread JavaScript. Namun pekerjaan CPU yang panjang tetap memblokir event loop dan perlu dipindahkan ke worker atau proses terpisah.

## Concept

Fokus penerapan **Asynchronous Programming** adalah await operasi I/O. Batasi concurrency. Tetapkan timeout untuk dependensi eksternal. Contoh berikut memperlihatkan konteks kategori JavaScript & TypeScript; sesuaikan dengan kontrak dan batas resource aplikasi.

## Prerequisites

- Node.js LTS yang masih didukung, npm, dan terminal.

## Implementation

1. Await operasi I/O.
2. Batasi concurrency.
3. Tetapkan timeout untuk dependensi eksternal.

### Contoh terfokus

Cuplikan ini berfokus pada konsep di atas. Untuk fragmen middleware, daftarkan pada aplikasi Express setelah dependensi yang dibutuhkan; contoh aplikasi lengkap tersedia pada Project References.

```js title="asynchronous-programming.mjs"
const delay = ms => new Promise(resolve => setTimeout(resolve, ms));
await Promise.all([delay(10), delay(20)]);
console.log("Kedua operasi selesai");
```

### Konteks kategori

```js title="example.mjs"
const notes = [{ id: 1, title: "Belajar backend", done: false }];
const titles = notes.filter(note => !note.done).map(note => note.title);
console.log(titles);
```

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk Asynchronous Programming, verifikasi langkah “Await operasi I/O” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.

## Security & Best Practices
