## Overview

Fungsi yang menerima dependensi secara eksplisit lebih mudah diuji. Arrow function menggunakan lexical this; method biasa mengambil this dari cara pemanggilannya.

## Concept

Fokus penerapan **Functions** adalah berikan nama sesuai tujuan. Batasi satu tanggung jawab. Return hasil daripada memodifikasi state global. Contoh berikut memperlihatkan konteks kategori JavaScript & TypeScript; sesuaikan dengan kontrak dan batas resource aplikasi.

## Prerequisites

- Node.js LTS yang masih didukung, npm, dan terminal.
- Materi [Getting Started](/docs/getting-started) dan dasar async/await.
- Folder latihan terpisah agar perubahan tidak memengaruhi data production.

## Installation

Contoh kategori ini memakai Node.js atau tools yang disebut pada contoh. Untuk berkas .mjs, jalankan node diikuti nama file.

## Project Structure

Simpan latihan Functions pada module fitur terkait. Pisahkan transport HTTP, aturan bisnis, dan akses data agar dapat diuji secara mandiri.


## Implementation

1. Berikan nama sesuai tujuan.
2. Batasi satu tanggung jawab.
3. Return hasil daripada memodifikasi state global.

### Contoh terfokus

Cuplikan ini berfokus pada konsep di atas. Untuk fragmen middleware, daftarkan pada aplikasi Express setelah dependensi yang dibutuhkan; contoh aplikasi lengkap tersedia pada Project References.

```js title="functions.mjs"
export function calculateTotal(items) {
  return items.reduce((total, item) => total + item.price * item.quantity, 0);
}
console.assert(calculateTotal([{ price: 5000, quantity: 2 }]) === 10000);
```

### Konteks kategori

```js title="example.mjs"
const notes = [{ id: 1, title: "Belajar backend", done: false }];
const titles = notes.filter(note => !note.done).map(note => note.title);
console.log(titles);
```

## Code Explanation

Dalam implementasi nyata, batasi satu tanggung jawab dan return hasil daripada memodifikasi state global sebelum meneruskan hasil ke bagian aplikasi berikutnya.

## API Examples

Topik ini merupakan konsep internal, sehingga tidak mendefinisikan endpoint tersendiri. Gunakan [Basic Express API](/docs/projects/basic-express-api) untuk mempelajari cara menerapkannya pada request HTTP.

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk Functions, verifikasi langkah “Berikan nama sesuai tujuan” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.

## Security & Best Practices

<Callout type="info" title="Batas implementasi">Contoh ringkas memperlihatkan konsep dan perlu disesuaikan dengan validasi, authorization, serta observability aplikasi.</Callout>

- Batasi satu tanggung jawab.
- Batasi hak akses dan data yang dikirim ke client.
- Return hasil daripada memodifikasi state global.
