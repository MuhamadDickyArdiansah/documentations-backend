## Overview

Generic mempertahankan hubungan tipe input dan output tanpa kehilangan informasi. Tambahkan constraint jika implementasi membutuhkan properti tertentu.

## Concept

Fokus penerapan **Generics** adalah mulai dari kebutuhan nyata. Gunakan extends sebagai constraint. Biarkan compiler melakukan inference. Contoh berikut memperlihatkan konteks kategori JavaScript & TypeScript; sesuaikan dengan kontrak dan batas resource aplikasi.

## Prerequisites

- Node.js LTS yang masih didukung, npm, dan terminal.
- Materi [Getting Started](/docs/getting-started) dan dasar async/await.
- Folder latihan terpisah agar perubahan tidak memengaruhi data production.

## Installation

Contoh kategori ini memakai Node.js atau tools yang disebut pada contoh. Untuk berkas .mjs, jalankan node diikuti nama file.

Simpan latihan Generics pada module fitur terkait. Pisahkan transport HTTP, aturan bisnis, dan akses data agar dapat diuji secara mandiri.

## Implementation

1. Mulai dari kebutuhan nyata.
2. Gunakan extends sebagai constraint.
3. Biarkan compiler melakukan inference.

### Contoh terfokus

Cuplikan ini berfokus pada konsep di atas. Untuk fragmen middleware, daftarkan pada aplikasi Express setelah dependensi yang dibutuhkan; contoh aplikasi lengkap tersedia pada Project References.

```ts title="generics.ts"
function first<T>(items: readonly T[]): T | undefined {
  return items[0];
}
const title = first(["Backend", "Testing"]); // string | undefined
```

### Konteks kategori

```js title="example.mjs"
const notes = [{ id: 1, title: "Belajar backend", done: false }];
const titles = notes.filter(note => !note.done).map(note => note.title);
console.log(titles);
```

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk Generics, verifikasi langkah “Mulai dari kebutuhan nyata” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.

## Security & Best Practices
