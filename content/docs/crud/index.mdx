## Tentang kategori ini

CRUD menerjemahkan lifecycle resource menjadi create, read, update, dan delete. Setiap operasi harus memiliki validasi, authorization, dan perilaku error yang terdokumentasi.

## Praktik

Jalankan contoh lokal dengan `npm run examples` dari root repository. Untuk pemeriksaan perilaku authentication dan CRUD, gunakan `npm run test:examples`.
