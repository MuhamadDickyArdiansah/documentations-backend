## Overview

Prisma membantu operasi bertipe tetapi query tetap perlu scope actor. Gabungkan ID dan ownerId dalam operasi tulis agar pemeriksaan dan perubahan tidak terpisah.

## Concept

Fokus penerapan **CRUD with Prisma** adalah generate Prisma client. Pilih field response. Tangani unique conflict dan record not found. Contoh berikut memperlihatkan konteks kategori CRUD Operations; sesuaikan dengan kontrak dan batas resource aplikasi.

### Contoh terfokus

Periksa dependensi dan konteks pada komentar kode. Adapter seperti repository, provider, atau prisma diberikan oleh composition root; fragmen bukan server terpisah. Untuk contoh utuh, lihat [Complete Backend Starter](/docs/projects/complete-backend-starter).

```js title="crud-with-prisma.mjs"
// Prisma 6.19; client, schema Note, DATABASE_URL, dan actor wajib tersedia.
export function createNoteRepository(prisma) {
  return {
    create: (actor, title) => prisma.note.create({ data: { ownerId: actor.id, title }, select: { id: true, title: true } }),
    list: actor => prisma.note.findMany({ where: { ownerId: actor.id }, take: 20, orderBy: [{ createdAt: "desc" }, { id: "desc" }] }),
    update: (actor, id, title) => prisma.note.updateMany({ where: { id, ownerId: actor.id }, data: { title } }),
    delete: (actor, id) => prisma.note.deleteMany({ where: { id, ownerId: actor.id } }),
  };
}
// count=0 pada update/delete berarti resource tidak tersedia dalam scope actor.
```

## API Examples

Contoh API lokal menggunakan resource notes. Endpoint mutasi membutuhkan bearer access token hasil login.

| Method | Endpoint | Authentication | Hasil |
| --- | --- | --- | --- |
| GET | /health | Tidak | 200, status proses |
| POST | /api/auth/login | Tidak | 200, pasangan token |
| GET | /api/notes | Bearer token | 200, daftar milik actor |
| POST | /api/notes | Bearer token | 201, note baru |

```json title="POST /api/notes — request"
{"title":"Belajar backend"}
```

```json title="201 — response shape"
{"data":{"id":"<note-id>","ownerId":"<user-id>","title":"Belajar backend"}}
```

Kirim header Content-Type: application/json. Token dan ID pada response merupakan placeholder; gunakan nilai dari server lokal. Lihat [Complete Backend Starter](/docs/projects/complete-backend-starter) untuk alur lengkap.

## Error Handling

Gunakan 401 untuk credential tidak valid, 404 untuk record yang tidak tersedia dalam scope actor, 409 untuk konflik, dan 422 untuk body yang tidak memenuhi schema. Response error berbentuk object error dengan code dan message. Untuk CRUD with Prisma, verifikasi langkah “Generate Prisma client” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.
