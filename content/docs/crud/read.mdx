## Overview

Read dapat berupa satu record atau daftar. Daftar harus dipaginasi dan query perlu dibatasi oleh ownership atau tenant agar data tidak bocor.

## Concept

Fokus penerapan **Read** adalah scope query ke actor. Select field publik. Return 404 jika record tidak tersedia. Contoh berikut memperlihatkan konteks kategori CRUD Operations; sesuaikan dengan kontrak dan batas resource aplikasi.

## Prerequisites

- Node.js LTS yang masih didukung, npm, dan terminal.
- Materi [Getting Started](/docs/getting-started) dan dasar async/await.
- Contoh API lokal pada folder examples; jalankan npm ci dari root.

## Installation

Dari root repository, jalankan perintah berikut. Dependensi contoh dikelola bersama lockfile project.

```bash title="terminal"
npm ci
npm run examples
```

## Implementation

1. Scope query ke actor.
2. Select field publik.
3. Return 404 jika record tidak tersedia.

### Contoh terfokus

Jalankan berkas .mjs ini dari root repository agar path import examples sesuai.

```js title="read.mjs"
import { createNoteRepository } from "./examples/crud/repository.mjs";
const repository = createNoteRepository();
const note = repository.create("u1", "Private");
console.assert(repository.find(note.id, "u2") === null);
```

### Konteks kategori

curl -i -X POST http://localhost:4000/api/notes \
  -H "Authorization: Bearer $ACCESS_TOKEN" \

## API Examples

Contoh API lokal menggunakan resource notes. Endpoint mutasi membutuhkan bearer access token hasil login.

| Method | Endpoint | Authentication | Hasil |
| --- | --- | --- | --- |
| GET | /health | Tidak | 200, status proses |
| POST | /api/auth/login | Tidak | 200, pasangan token |
| GET | /api/notes | Bearer token | 200, daftar milik actor |
| POST | /api/notes | Bearer token | 201, note baru |

```json title="POST /api/notes — request"
{"title":"Belajar backend"}
```

```json title="201 — response shape"
{"data":{"id":"<note-id>","ownerId":"<user-id>","title":"Belajar backend"}}
```

Kirim header Content-Type: application/json. Token dan ID pada response merupakan placeholder; gunakan nilai dari server lokal. Lihat [Complete Backend Starter](/docs/projects/complete-backend-starter) untuk alur lengkap.

## Error Handling

Gunakan 401 untuk credential tidak valid, 404 untuk record yang tidak tersedia dalam scope actor, 409 untuk konflik, dan 422 untuk body yang tidak memenuhi schema. Response error berbentuk object error dengan code dan message. Untuk Read, verifikasi langkah “Scope query ke actor” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.

Uji Read dengan input valid, input kosong, dan kegagalan dependensi. Pastikan perilaku “scope query ke actor” sesuai kontrak. Tambahkan test tanpa token dan test akses lintas user.
