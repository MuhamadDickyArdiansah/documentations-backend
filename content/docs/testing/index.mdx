## Tentang kategori ini

Test yang baik memeriksa perilaku yang terlihat dan kegagalan yang relevan. Utamakan aturan bisnis, batas keamanan, dan kontrak endpoint daripada detail implementasi.

## Urutan belajar

Baca topik berikut sesuai urutan, atau pilih materi yang dibutuhkan sebagai referensi.

<Cards>
<Card title="Testing Fundamentals" href="/docs/testing/testing-fundamentals">Test yang baik memeriksa perilaku yang terlihat dan kegagalan yang relevan.</Card>
<Card title="Unit Testing" href="/docs/testing/unit-testing">Unit test memeriksa logika kecil tanpa database atau jaringan.</Card>
<Card title="Integration Testing" href="/docs/testing/integration-testing">Integration test memverifikasi beberapa komponen yang bekerja bersama.</Card>
<Card title="API Testing" href="/docs/testing/api-testing">API test mengirim request HTTP nyata dan memeriksa status, header, serta body.</Card>

<Card title="Authentication Testing" href="/docs/testing/authentication-testing">Test authentication harus mencakup credential salah, token kedaluwarsa, signature tidak valid, refresh replay, dan logout.</Card>

## Praktik

Jalankan contoh lokal dengan `npm run examples` dari root repository. Untuk pemeriksaan perilaku authentication dan CRUD, gunakan `npm run test:examples`.
