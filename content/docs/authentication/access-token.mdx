## Overview

Access token memberi akses berumur pendek. Token bearer dapat digunakan siapa pun yang memilikinya, sehingga kebocoran harus dibatasi lewat masa berlaku pendek dan penyimpanan yang sesuai.

## Concept

Fokus penerapan **Access Token** adalah tetapkan expiry. Batasi audience. Hindari menyimpan token di URL. Contoh berikut memperlihatkan konteks kategori Authentication; sesuaikan dengan kontrak dan batas resource aplikasi.

## Prerequisites

- Node.js LTS yang masih didukung, npm, dan terminal.
- Materi [Getting Started](/docs/getting-started) dan dasar async/await.
- Contoh API lokal pada folder examples; jalankan npm ci dari root.

## Implementation

1. Tetapkan expiry.
2. Batasi audience.
3. Hindari menyimpan token di URL.

### Contoh terfokus

Cuplikan route memakai helper dan state dari examples/complete-backend/app.mjs. Implementasi lengkap yang dapat dijalankan ada pada [JWT Authentication](/docs/authentication/jwt-authentication). Cuplikan modul mandiri dapat disimpan sebagai .mjs; import examples menggunakan path relatif dari root repository.

```js title="access-token.mjs"
import { randomBytes, createHash, randomUUID } from 'node:crypto';
import { SignJWT, jwtVerify } from 'jose';
export function createTokens(secret) {
  if (Buffer.byteLength(secret || '') < 32) throw new Error('JWT_SECRET must contain at least 32 bytes');
  const key = new TextEncoder().encode(secret);
  return {
    async sign(userId, sessionId) {
      return new SignJWT({ sid: sessionId }).setProtectedHeader({ alg: 'HS256', typ: 'JWT' })
        .setSubject(userId).setIssuer('backend-handbook').setAudience('handbook-api')
        .setIssuedAt().setJti(randomUUID()).setExpirationTime('15m').sign(key);
    },
    async verify(token) {
      const { payload } = await jwtVerify(token, key, { algorithms: ['HS256'], issuer: 'backend-handbook', audience: 'handbook-api', typ: 'JWT' });
      if (typeof payload.sub !== 'string' || typeof payload.sid !== 'string') throw new Error('Invalid claims');
      return payload;
    },
  };
}
export function refreshToken() { return randomBytes(32).toString('base64url'); }
export function digest(token) { return createHash('sha256').update(token).digest('hex'); }
```

## API Examples

Contoh API lokal menggunakan resource notes. Endpoint mutasi membutuhkan bearer access token hasil login.

| Method | Endpoint | Authentication | Hasil |
| --- | --- | --- | --- |
| GET | /health | Tidak | 200, status proses |
| POST | /api/auth/login | Tidak | 200, pasangan token |
| GET | /api/notes | Bearer token | 200, daftar milik actor |
| POST | /api/notes | Bearer token | 201, note baru |

```json title="POST /api/notes — request"
{"title":"Belajar backend"}
```

```json title="201 — response shape"
{"data":{"id":"<note-id>","ownerId":"<user-id>","title":"Belajar backend"}}
```

Kirim header Content-Type: application/json. Token dan ID pada response merupakan placeholder; gunakan nilai dari server lokal. Lihat [Complete Backend Starter](/docs/projects/complete-backend-starter) untuk alur lengkap.

## Error Handling

Gunakan 401 untuk credential tidak valid, 404 untuk record yang tidak tersedia dalam scope actor, 409 untuk konflik, dan 422 untuk body yang tidak memenuhi schema. Response error berbentuk object error dengan code dan message. Untuk Access Token, verifikasi langkah “Tetapkan expiry” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.

## Security & Best Practices

<Callout type="warn" title="Batas implementasi">Contoh adalah sarana belajar dan bukan audit keamanan. Untuk production, gunakan TLS, shared persistent storage, rate limit terdistribusi, serta pengelolaan secret yang sesuai infrastruktur.</Callout>

- Batasi audience.
- Batasi hak akses dan data yang dikirim ke client.
- Hindari menyimpan token di URL.

## Testing

Uji Access Token dengan input valid, input kosong, dan kegagalan dependensi. Pastikan perilaku “tetapkan expiry” sesuai kontrak. Tambahkan test tanpa token dan test akses lintas user.

```bash title="verifikasi contoh utama"
npm run test:examples
```
