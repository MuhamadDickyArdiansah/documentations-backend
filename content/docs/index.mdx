Mulai dari konsep, praktikkan dengan kode, lalu pastikan perilakunya melalui pengujian. Dokumentasi ini disusun untuk developer yang ingin belajar secara runtut maupun mencari referensi saat membangun aplikasi.

<Callout type="info" title="Belajar dengan praktik">Contoh API lokal ada di folder examples. Jalankan npm run test:examples sebelum mengubah implementasi.</Callout>

## Referensi

Sumber konsep dan bacaan lanjutan untuk materi ini:

- **Referensi dari [Node.js — Introduction to Node.js](https://nodejs.org/en/learn/getting-started/introduction-to-nodejs)** — Model runtime dan dasar penggunaan Node.js.
- **Referensi dari [Express — Routing Guide](https://expressjs.com/en/guide/routing/)** — Route, router, dan pemetaan endpoint HTTP.
- **Referensi dari [IETF — RFC 9110: HTTP Semantics](https://www.rfc-editor.org/rfc/rfc9110)** — Semantik method, status code, header, dan representasi.

Penjelasan dan contoh kode pada handbook ditulis sebagai materi pembelajaran mandiri; bukan salinan resmi dari sumber tersebut. Cocokkan versi API pada referensi dengan versi dependensi contoh.
