## Overview

API yang maintainable memisahkan transport, use case, dan persistence. Kontrak endpoint tetap stabil walaupun ORM atau layanan penyimpanan berubah.

## Concept

Fokus penerapan **API Architecture** adalah definisikan DTO. Pindahkan bisnis ke service. Uji kontrak response secara otomatis. Contoh berikut memperlihatkan konteks kategori Express.js; sesuaikan dengan kontrak dan batas resource aplikasi.

## Prerequisites

- Node.js LTS yang masih didukung, npm, dan terminal.
- Materi [Getting Started](/docs/getting-started) dan dasar async/await.
- Contoh API lokal pada folder examples; jalankan npm ci dari root.

## Installation

Dari root repository, jalankan perintah berikut. Dependensi contoh dikelola bersama lockfile project.

```bash title="terminal"
npm ci
npm run examples
```

## Project Structure

Simpan latihan API Architecture pada module fitur terkait. Pisahkan transport HTTP, aturan bisnis, dan akses data agar dapat diuji secara mandiri.

```text title="struktur referensi"
src/
  features/
    notes/
      notes.routes.mjs
      notes.service.mjs
      notes.repository.mjs
  app.mjs
  server.mjs
```

## Implementation

1. Definisikan DTO.
2. Pindahkan bisnis ke service.
3. Uji kontrak response secara otomatis.

### Contoh terfokus

Cuplikan ini berfokus pada konsep di atas. Untuk fragmen middleware, daftarkan pada aplikasi Express setelah dependensi yang dibutuhkan; contoh aplikasi lengkap tersedia pada Project References.

```text title="api-architecture.text"
HTTP controller -> use case -> repository interface
                                |
                                +-> PostgreSQL adapter
                                +-> in-memory test adapter
```

### Konteks kategori

```js title="app.mjs"
import express from "express";
const app = express();
app.use(express.json({ limit: "16kb" }));
app.get("/health", (_req, res) => res.json({ data: { status: "ok" } }));
app.use((_req, res) => res.status(404).json({ error: { code: "NOT_FOUND" } }));
app.listen(4000, "127.0.0.1");
```

## Code Explanation

API yang maintainable memisahkan transport, use case, dan persistence. Kontrak endpoint tetap stabil walaupun ORM atau layanan penyimpanan berubah. Dalam implementasi nyata, pindahkan bisnis ke service dan uji kontrak response secara otomatis sebelum meneruskan hasil ke bagian aplikasi berikutnya.

## API Examples

Contoh API lokal menggunakan resource notes. Endpoint mutasi membutuhkan bearer access token hasil login.

| Method | Endpoint | Authentication | Hasil |
| --- | --- | --- | --- |
| GET | /health | Tidak | 200, status proses |
| POST | /api/auth/login | Tidak | 200, pasangan token |
| GET | /api/notes | Bearer token | 200, daftar milik actor |
| POST | /api/notes | Bearer token | 201, note baru |

```json title="POST /api/notes — request"
{"title":"Belajar backend"}
```

```json title="201 — response shape"
{"data":{"id":"<note-id>","ownerId":"<user-id>","title":"Belajar backend"}}
```

Kirim header Content-Type: application/json. Token dan ID pada response merupakan placeholder; gunakan nilai dari server lokal. Lihat [Complete Backend Starter](/docs/projects/complete-backend-starter) untuk alur lengkap.

## Error Handling

Gunakan 401 untuk credential tidak valid, 404 untuk record yang tidak tersedia dalam scope actor, 409 untuk konflik, dan 422 untuk body yang tidak memenuhi schema. Response error berbentuk object error dengan code dan message. Untuk API Architecture, verifikasi langkah “Definisikan DTO” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.

## Security & Best Practices

<Callout type="info" title="Batas implementasi">Contoh ringkas memperlihatkan konsep dan perlu disesuaikan dengan validasi, authorization, serta observability aplikasi.</Callout>

- Pindahkan bisnis ke service.
- Batasi hak akses dan data yang dikirim ke client.
- Uji kontrak response secara otomatis.

## Testing

Uji API Architecture dengan input valid, input kosong, dan kegagalan dependensi. Pastikan perilaku “definisikan dto” sesuai kontrak. Tambahkan test tanpa token dan test akses lintas user.

```bash title="verifikasi contoh utama"
npm run test:examples
```
