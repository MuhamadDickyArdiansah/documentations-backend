## Overview

Repository menyatakan operasi penyimpanan dalam bahasa domain. Implementasi in-memory berguna untuk unit test, tetapi tetap perlu integration test untuk SQL nyata.

## Concept

Fokus penerapan **Repository Pattern** adalah buat interface minimal. Hindari bocor ORM query object. Uji adapter database secara terpisah. Contoh berikut memperlihatkan konteks kategori Architecture & Best Practices; sesuaikan dengan kontrak dan batas resource aplikasi.

## Prerequisites

- Node.js LTS yang masih didukung, npm, dan terminal.
- Materi [Getting Started](/docs/getting-started) dan dasar async/await.
- Folder latihan terpisah agar perubahan tidak memengaruhi data production.

## Implementation

1. Buat interface minimal.
2. Hindari bocor ORM query object.
3. Uji adapter database secara terpisah.

### Contoh terfokus

Periksa dependensi dan konteks pada komentar kode. Adapter seperti repository, provider, atau prisma diberikan oleh composition root; fragmen bukan server terpisah. Untuk contoh utuh, lihat [Complete Backend Starter](/docs/projects/complete-backend-starter).

```js title="repository-pattern.mjs"
import { randomUUID } from 'node:crypto';
// In-memory adapter for learning. Replace with transactional persistent storage before deployment.
export function createNoteRepository() {
  const rows = new Map();
  return {
    create(ownerId, title) { const note = { id: randomUUID(), ownerId, title }; rows.set(note.id, note); return { ...note }; },
    list(ownerId, offset = 0, limit = 20) { return [...rows.values()].filter(row => row.ownerId === ownerId).slice(offset, offset + limit).map(row => ({ ...row })); },
    find(id, ownerId) { const row = rows.get(id); return row?.ownerId === ownerId ? { ...row } : null; },
    update(id, ownerId, title) { const row = rows.get(id); if (row?.ownerId !== ownerId) return null; row.title = title; return { ...row }; },
    delete(id, ownerId) { const row = rows.get(id); return row?.ownerId === ownerId ? rows.delete(id) : false; },
  };
}
```

### Konteks kategori

```js title="notes.service.mjs"
export function createNoteService(repository) {
  return {
    async findForUser(id, actor) {
      const note = await repository.findById(id);
      return note?.ownerId === actor.id ? note : null;
    },
  };
}
```

## Error Handling

Buat kegagalan terlihat pada batas module. Tangani input salah secara eksplisit dan pertahankan informasi penyebab pada log internal. Untuk Repository Pattern, verifikasi langkah “Buat interface minimal” ketika hasil tidak sesuai harapan. Jangan mengembalikan secret atau stack trace ke client.

## Security & Best Practices

<Callout type="info" title="Batas implementasi">Contoh ringkas memperlihatkan konsep dan perlu disesuaikan dengan validasi, authorization, serta observability aplikasi.</Callout>
