## Tentang kategori ini

MVC memisahkan model, representasi, dan controller. Dalam JSON API, representasi biasanya DTO, sedangkan aturan bisnis sebaiknya tetap berada di service atau domain.

## Praktik

Jalankan contoh lokal dengan `npm run examples` dari root repository. Untuk pemeriksaan perilaku authentication dan CRUD, gunakan `npm run test:examples`.

## Referensi

Sumber konsep dan bacaan lanjutan untuk materi ini:

- **Referensi dari [Robert C. Martin — The Clean Architecture](https://blog.cleancoder.com/uncle-bob/2012/08/13/the-clean-architecture.html)** — Aturan dependensi dan pemisahan domain dari infrastruktur.
- **Referensi dari [Martin Fowler — Service Layer](https://martinfowler.com/eaaCatalog/serviceLayer.html)** — Boundary service dan orkestrasi operasi bisnis.

Penjelasan dan contoh kode pada handbook ditulis sebagai materi pembelajaran mandiri; bukan salinan resmi dari sumber tersebut. Cocokkan versi API pada referensi dengan versi dependensi contoh.
